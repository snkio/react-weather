## 🛠️ Built With:
React / JS / Tailwind CSS

## 💫 Features:

- **Find location:** search by city (OpenMeteo)
- **Detect day/night:** swap icons based on time of day
- **7-day forecast:** min/max temperature, weather icons, precipitation chance
- **Hourly forecast:** temperature, weather icons

## 🌐 Local:

```bash 
git clone https://github.com/snkio/react-weather.git
cd react-weather && npm install && npm run dev
```
